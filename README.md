# この譜面なんでしょう

CHUNITHMの譜面動画を流して、曲名や難易度を隠したまま譜面定数を当てるクイズ。

- **問題リスト**: YouTubeのURL・定数・難易度・曲名・開始/終了秒を登録（1行1問の一括貼り付け、JSONで共有も可）
- **マスク調整**: 黒い四角をドラッグして曲名やスコアを隠す。全問共通と動画ごとの個別マスク
- **クイズ**: ランダム出題。ピタリで100点、0.1ずれるごとに-25点

問題とマスクはブラウザ（localStorage）に保存される。友達と同じ問題で遊ぶときはJSONで渡す。

ローカルで動かすときは `python -m http.server 8000` で `http://localhost:8000` を開く（ファイル直開きだとYouTubeが再生できない）。
